01 · KEY FEATURES

VM100 주요 기능 한눈에

기존 휴대용 진동측정기의 한계를 넘어선 멀티채널·멀티모드 측정 플랫폼입니다.

📡
9채널 동시 계측
단축 9개 또는 3축 3개 구성. 하나의 기계에서 여러 포인트를 동시에 기록해 시간을 절약합니다.
📊
FFT 주파수 분석
최대 65,536포인트, 1Hz~22kHz 범위. 워터폴(50 스펙트럼) 및 스펙트로그램(300 스펙트럼) 모드 지원.
🎚️
Third-Octave 분석
1~160 Hz, 21개 1/3 옥타브 밴드. VC·Nano 기준선 내장으로 정밀 장비 설치 환경을 현장 즉시 평가.
🗺️
머신 모니터링·경로 측정 (VM100-MAC)
측정 위치·기계·경보 기준을 등록해 두고 NFC 태그로 순회 측정. 상태를 신호등(녹색·황색·적색)으로 자동 판정, ISO 기준 자동 매핑.
🔩
엔벨로프 분석·베어링 진단 (VM100-ENV)
BPFI·BPFO·FTF·BSF 결함 주파수 마커 자동 표시로 롤러 베어링 손상을 조기 감지. 유지보수 계획 수립에 활용.
⚖️
발란싱 1면·2면 (VM100-BAL)
타코미터 입력 기반 1면/2면 밸런싱. 불균형량·교정 무게·각도를 현장에서 계산·표시, 별도 PC 불필요.
🧑
인체진동 측정 (VM100-HUM)
ISO 5349 손-팔 진동, ISO 2631-1 전신 진동, GB/T 4970 차량 승차감(시트·등받이·발판 3점)까지 하나의 라이선스로 지원. 일일 노출량(A(8))·잔여 시간 표시.
📈
런업/코스트다운 분석 (VM100-RPM)
기동·정지 과정의 진폭/회전수(Amplitude-RPM) 곡선으로 공진 주파수를 탐색. 회전 기계 동적 특성 분석.
🔬
VC/Nano 정밀 진동 (VM100-VC)
반도체 장비·전자현미경 설치 환경의 극미세 진동 평가. Third-Octave 화면에 VC·Nano 기준선 직접 표시.
🏷️
TEDS 센서 자동 감지
TEDS 지원 센서를 연결하면 감도·직렬번호가 자동으로 인식. NFC 태그로 측정 포인트 자동 식별.
💾
CSV·BMP·WAV 저장
측정값은 CSV, 화면은 BMP, 원시 신호는 WAV로 저장. USB-C로 PC 연결 시 별도 드라이버 없이 Mass Storage로 인식.

센서 장착 방법이 고주파 측정 정확도를 좌우합니다

VM100의 FFT 분석은 최대 22kHz까지 측정하지만, 센서 장착 시 질량 증가와 장착 강성 저하가 겹치면 고주파 영역에서 실제 감도가 크게 떨어집니다. 스터드 마운팅이 가장 우수하고, 마그네틱·접착제·프로브 순으로 고주파 성능이 낮아집니다.

장착 방법별 상세 비교는 진동센서 원리·설치 가이드에서 확인할 수 있습니다.

FAQ

자주 묻는 질문

VM100은 최대 9채널(단축 9개 또는 3축 3개) 동시 계측이 가능한 반면, VM25는 단일 채널 측정기입니다. VM100은 FFT, Third-Octave, 인체진동, 발란싱, 런업/코스트다운, VC/Nano 등 VM25에 없는 고급 기능을 포함합니다. 다수 측정 포인트를 한 번에 기록하거나 심층 분석이 필요한 환경에 VM100이 적합합니다.
작업자가 기계·차량에서 받는 진동 노출량을 평가하는 측정으로, VM100은 옵션 라이선스 VM100-HUM 하나로 세 가지 규격을 모두 지원합니다. ISO 5349 기반 손-팔(Hand-Arm) 진동, ISO 2631-1 기반 전신(Whole-Body) 진동, 차량·선박 좌석·등받이·발판 3점 동시 측정 기반 GB/T 4970-2009 승차감 평가까지 하나의 모듈에서 처리하며, 하루 최대 노출량(A(8)) 및 잔여 시간을 실시간으로 표시합니다.
VM100-MAC은 다수의 설비·측정 포인트를 경로(Route) 단위로 등록해 정기적으로 순회 측정하고 이력을 관리하는 옵션 모듈입니다. NFC 태그로 측정 지점을 자동 식별하고, 각 포인트의 진동 트렌드를 추적해 관리 기준(경보/위험) 초과 여부를 알려줍니다. 설비 예지보전(PdM) 정기 점검에 적합합니다.
1/3 옥타브 분석은 반도체·광학 장비 설치 환경 평가(VC/Nano 기준), 건물·구조물 진동 평가, 음향·소음 분석에 주로 사용됩니다. VM100은 VM100-VC 라이선스로 VC 및 Nano 기준선을 화면에 직접 표시하여 현장에서 즉시 적합 여부를 판단할 수 있습니다.
VM100은 1평면(정적 불균형) 또는 2평면(동적 불균형) 발란싱을 지원합니다. 타코미터 입력으로 RPM을 감지하고, 가속도 센서로 진동 진폭과 위상을 측정하여 불균형량 및 교정 무게·위치를 계산합니다. 별도 소프트웨어 없이 터치 스크린만으로 현장 발란싱 작업을 완결합니다.
VC(Vibration Criteria)는 반도체 장비·전자현미경·리소그래피 장비 등 진동에 민감한 정밀 장비 설치 환경 평가 기준입니다. Nano 기준은 나노급 정밀 공정 환경에 적용됩니다. VM100의 Third-Octave 분석 화면에 기준선을 직접 표시하여 현장에서 즉시 판단할 수 있습니다.
측정값은 CSV로 저장됩니다. 화면 캡처는 BMP, 원시 신호는 WAV 파일로 기록됩니다. PC 연결은 USB Type-C(Mass Storage 모드, FAT 파일 시스템)로 파일을 직접 복사하며 별도 드라이버가 필요 없습니다. 배터리는 USB-C로 충전하며 1회 충전으로 10~14시간 연속 사용이 가능합니다.
